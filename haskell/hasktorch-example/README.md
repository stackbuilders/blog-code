# Hasktorch Skeleton

Basic MNIST CNN example with Hasktorch based on [Hasktorch](https://github.com/hasktorch/hasktorch-skeleton) template. 


Steps to run it locally. 

1. get into nix 
```sh
nix develop
```
2. build 
```sh
cabal build
```
3. run (model will be saved inot static-mnist-cnn.pt file)
```sh 
cabal run
```
